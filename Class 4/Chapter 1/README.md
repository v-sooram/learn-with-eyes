## 4. Food Preservation

### ISL Video Resource
- ISLRTC Dictionary Term: **Temporary Preservation - ISLRTC**

### Alternative Visual / Layout Suggestion
Step-by-step visual process grid (Before vs. After):
- 🧊 **Refrigeration:** Keeping milk/vegetables cold stops germs.
- ☀️ **Sun Drying:** Removing water so food lasts long (e.g., red chillies/fish).
- 🧂 **Pickling / Salting:** Adding salt and oil to preserve mangoes/lemon.
- 🥫 **Canning / Boiling:** Heating to kill germs and sealing tightly in a container.

### Illustrated Notations (Bottom of Page / Footer Cards)
- **Preservation:** [Icon: Clock ⏰ + Apple 🍎] → Ways to save food so it does not spoil or go bad.
- **Spoil:** [Icon: Rotten fruit with flies 🪰] → Food becoming bad and unsafe to eat.
